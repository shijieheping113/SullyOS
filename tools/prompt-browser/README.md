# 提示词看板（本机）

看 SullyOS 里真正的功能提示词，复制后贴给 Build 改。

## 打开

双击 `D:\SullyOS\打开提示词看板.bat`。浏览器会自己弹出。那个黑窗口留着，关掉它看板就关了。

## 改提示词给别的 AI

1. 左边选 App，中间勾要改的几条。
2. 右边用人话写下「要怎么改」。
3. 点右上角「复制给 AI 去改」，粘贴给 Build。

可以一次勾好几条。每条的意见会分开写清楚。

## 关掉

关掉标题是「提示词看板」的黑窗口。只关这个，别关别的。

## 加一条

编辑 `registry.json`。找不到符号会标红，不会拿旁边代码顶上。
