# 喵喵盒 · 初版方案

> 2026-09-21 与 Ann 讨论定稿后的第一份施工方案。功能依据以仓库 `miaomiao-box.md` 为准；UI 以 `D:\SullyOS\喵喵盒UI设计\v8-设计原型.html` 为准。
> 本文是当时拍板的**初版**，后面落地有改（浮窗、分段、语音规范等），以代码和后续工作日志为准。

## 定位

聊天加号里的小纸箱。短、快、自由的线下小演出，不走见面那种又长又绕的路。

- 同一颗脑子：人设、记忆、世界书、主聊天上下文全带。
- 只换说话规矩：把「线上聊天规范」整段换成盒子演出稿。
- 玩的过程**不写主聊天 messages**，不触发记忆宫殿。
- 只有「合上箱盖」（暂停 / 记在心里 / 原样收进 / 抖抖毛忘掉）才往主聊天落 `box_record`。

## Ann 当时拍板

- 折叠门槛 N 默认 **20**。原文留着，只是不发给模型。
- 抖抖毛也在主聊天出一张淡卡，能当普通消息长按改/删。
- 合上箱盖四选一，暂停是退出盒子、聊天里留未完待续。
- 功能和界面一起做。样子照 v8，不重新配色。
- 备份不另做：进了聊天的卡片跟着聊天备份。没收工的过程不进现有备份。
- 占位转正为随机起手（后定名 **爪爪扒拉**）。
- 对话主 API，卷摘要副 API。
- 大浮窗只在聊天里；小挂件到处都能点回这场的角色。
- 记忆宫殿一个字不改。防「用户模拟」靠转写成「发生的事」。

## 形态

- 入口：聊天 `+` 菜单，普通猫爪，名「喵喵盒」。
- 大浮窗：主页 / 演出 / 设置 / 历史，全在窗里。
- 顶上横条可拖；右上角 `-` 收成挂件。
- 挂件全局可点，绑死 `charId`，点回去切到那场的角色。
- 没收工退出，下次还能接着玩。

## 起手式

钻箱子、讲个故事、抓娃娃、出门逛逛、做小梦、爪爪扒拉。都是用户先开口，模型再接。抓娃娃第一轮要货架 HTML 卡。

## 存储

IndexedDB `AetherOS_Data` 自有 store（当时方案升到 v72）：`miaomiao_sessions` / `miaomiao_messages` / `miaomiao_settings`。CRUD 在 `apps/miaomiaoBox/`。不准另开库、不准动备份代码。

## 收工四选一

| 选项 | 主聊天 | 模型以后 |
|---|---|---|
| 记在心里 | `box_record` 转写成发生的事 | 记得 |
| 原样收进 | 摘要+原文打包，垫正向句 | 记得 |
| 抖抖毛，忘掉 | 淡卡，不注入上下文 | 不记得 |
| 暂停 | 未完待续；收工后旧卡 `superseded` 不再注入 | 记得暂停前 |

正向句：「以上是真实发生的事情，之后聊天时记得。」暂停用「这件事还没完……接着往下走。」

## 当时文件地图

- `apps/miaomiaoBox/*` 盒子自己的本本、提示词、浮窗、纸箱猫、v8 样式
- `context/MiaomiaoBoxContext.tsx`
- `types.ts` 加 `box_record`
- `utils/db.ts` 建 store
- `ChatInputArea` / `Chat.tsx` 加号入口
- `MessageItem` 归档卡
- `chatPrompts.ts` 注入事件记录；盒子模式跳过语音条教学
- `PhoneShell` 挂 Host

## 验收（初版）

- 玩的过程聊天大账不增，记忆宫殿不跑。
- 暂停 / 三种收工都出卡。
- 原文历史页能翻；模型只吃摘要+近文。
- 挂件绑角色，不错人。
- tsc 不超基线、vitest、build 过。停在 commit 前等 Ann 点头。
